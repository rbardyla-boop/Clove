Cognitive Science for Operators

Why You Can't Stop Overthinking: The Rumination Loop Explained

By Ryan Bardyla · Canadian Army Veteran · From The Biological Bruise

The Loop That Won't Close

The conversation ended three days ago. You have replayed it approximately forty times. Each replay produces a slightly different version — what you should have said, what they probably meant, what the look on their face indicated, what it will mean going forward. None of the versions produce resolution. Each one generates new threads. The loop doesn't close. It just gets longer.

You've told yourself to stop thinking about it. You've distracted yourself. You've talked it through with someone who told you it's not a big deal. None of it worked for longer than the duration of the distraction, and the moment the distraction lifted, the loop resumed exactly where it left off, as if the interruption hadn't happened.

This is not overthinking in the sense of excessive intellectual processing. It is a specific cognitive pattern — rumination — that operates on its own logic, serves its own function, and does not respond to instructions to stop. Understanding what it's actually doing is the first step toward giving it a reason to stop.

What the Loop Is Trying to Do

Rumination is not random. It is the brain's problem-solving system applied to a problem that hasn't been resolved. The loop runs because the system is designed to run until it finds an answer — and the problem it's working on doesn't have one, or the available answer requires something the brain is trying to avoid, or the problem is fundamentally unsolvable through analysis alone.

The loop structure is: review the event → try to find the causal explanation → try to determine what should have been done differently → try to predict what happens next → fail to reach a satisfying conclusion → restart. The restart is not a malfunction. It's the search algorithm running again because the previous pass didn't return a result that satisfied the exit condition.

The exit condition is usually something the brain cannot actually deliver: certainty that the situation will resolve well, confirmation that you are not at fault, assurance that the relationship is intact, or resolution of the unresolvable ambiguity about what the other person meant or feels. Analysis cannot produce certainty about another person's internal state. The loop will run indefinitely searching for what analysis cannot find.

"Rumination is not the problem. It's the symptom of a problem the brain has classified as unsolved and unresolvable. The loop won't close until you either give it a real answer or explicitly close the case file yourself."

What Feeds It

Distraction feeds it. The loop has an elastic quality: compress it and it expands the moment the pressure lifts. Distraction doesn't resolve the problem the loop is working on — it just interrupts the processing temporarily. The brain stores the unfinished loop and resumes it when the distraction is removed, often with increased intensity because suppression of an active problem-solving process adds urgency to the signal when it returns.

Rumination partners with two cognitive distortions that sustain it: catastrophizing (the conclusion the loop keeps reaching is the worst-case scenario, which justifies continued analysis) and emotional reasoning (the distress produced by the loop is taken as evidence that the threat is real, which justifies continued attention to it). The distress produces the emotional reasoning that validates the distress. The loop is self-sustaining.

The specific conditions in which rumination intensifies: lying down to sleep, physical environments associated with the triggering event, idle periods with no task demand, and the moment of waking before other inputs have established context. These are periods of reduced external input, which give the loop access to more of the brain's processing capacity. The brain does not have a standby mode. When there is no incoming signal, it works on unsolved problems. If you have an open loop, reduced external stimulation means the loop gets more bandwidth.

Closing the Loop

TOOL 01
The Explicit Case Close
The loop stays open because the brain has not received a close signal. You can issue one deliberately. Write it out: what happened, what remains uncertain, what the outcome is likely to be, and then — explicitly — the decision to close the case: "I have processed this as far as analysis allows. The remaining uncertainty cannot be resolved through further thought. The case is closed. I will act on new information if it arrives." The act of writing and the explicit close statement gives the problem-solving system a resolution signal it can process. It is not magic. But it is more effective than telling yourself to stop thinking, because it provides a reason rather than just an instruction.
TOOL 02
The Scheduled Worry Window
Assign rumination a specific time slot: twenty minutes, at a fixed time, every day. Outside that window, when the loop starts, the instruction is: "Not now — you have a slot." At the scheduled time, run the loop deliberately. This sounds counterintuitive. What it does is give the problem-solving system a scheduled run time, which reduces its urgency to interrupt at other times. The brain relaxes its insistence on solving the problem immediately when it has a confirmed future slot. The worry window also has a time limit, which trains the association between "beginning to think about this" and "stopping at a defined endpoint."
TOOL 03
The Solvable/Unsolvable Sort
For the specific problem the loop is working on: is there an action available that would produce a resolution? If yes — make the call, send the message, have the conversation — the loop has a task it can close on. Run the task. If no — if the thing being analyzed cannot be resolved through any available action — this is the second category. The problem is unsolvable, and the loop is running analysis on a problem that analysis cannot solve. That is important information. The exit for unsolvable problems is not continued analysis. It is the explicit acknowledgment that analysis has reached its limit, and the deliberate practice of allowing the uncertainty to remain unresolved.
TOOL 04
The Absorption Interrupt
Distraction doesn't work because it doesn't require enough of the brain's processing capacity to actually displace the loop. The replacement activity needs to be absorbing enough to genuinely occupy the capacity the loop was using. This means: something that requires active decision-making, physical coordination, or social engagement — not passive consumption. Running a protocol drill, playing an instrument, a high-intensity physical session, or a real conversation (not about the rumination topic) that requires genuine engagement. The interrupt works when the replacement demand is high enough that the loop cannot run concurrently. Build a specific list of activities that reliably meet this threshold for you.

The Loop Is Not the Enemy

The rumination loop is the brain doing exactly what it's built to do: it found an unresolved problem and assigned processing resources to solving it. The fact that it keeps running is evidence that it's working, not that it's broken. The problem is the assignment — the brain has been given a problem that cannot be solved through analysis, and no one told it that.

The exit is not silencing the problem-solving system. It is closing the case — either through action, if action is available, or through explicit acknowledgment of irresolvable uncertainty, if it isn't. The brain needs a resolution signal. When you provide one that's accurate — "this is uncertain and will remain uncertain, and I am proceeding anyway" — the loop has what it was searching for. Not the answer it wanted. An honest account of the situation. That's usually enough to let it rest.

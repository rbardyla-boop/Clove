Host on Cloudflare Pages 
1. Save this file locally as "index.html".
2. Create a clean folder containing only this index file.
3. Open the Cloudflare Dashboard → Workers & Pages.
4. Click "Create application" → "Pages" → "Upload assets"
   (or connect a Git repo containing the file).
5. Project settings:
   - Build command:    (leave empty)
   - Build output dir: /
   - Framework preset: None
6. Deploy. To attach a custom domain (e.g. mindmachine.app),
   open the Pages project → Custom domains → Add domain,
   then point the CNAME to .pages.dev.
7. Service worker caches all assets on first load, so the app
   is fully playable offline after one online visit.
